Entry for the make.fun bounty "The Best Advice I Ever Got": one sentence,
200 characters or fewer, about the best advice the writer ever received.

## The entry

```
My father said the job isn't done when the box is delivered, it's done when the person who signed for it would trust you again tomorrow.
```

## Run

```
python3 main.py
```

Writes the line to `/output/entry.txt` (136 characters, one sentence).

## Why this line

It is advice a father actually gave his courier son, in the words he
would use: the delivery is not the end of the job, the customer's trust
tomorrow is. It is specific to a real working life, it holds beyond the
moment it was spoken, and it leaves the reader with a standard to carry
into any job.
